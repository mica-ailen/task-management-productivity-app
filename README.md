# Task-management-Productivity-App

<p>A lightweight web application that helps you stay organized and productive by managing your daily tasks efficiently.</p>
<h2>✨ Features</h2>
<ul>
  <li><strong>Add Tasks</strong> - Quickly create new tasks for your to-do list</li>
  <li><strong>Edit Tasks</strong> - Modify existing tasks with ease</li>
  <li><strong>Delete Tasks</strong> - Remove completed or unnecessary items</li>
  <li><strong>Mark Complete</strong> - Track progress by checking off finished tasks</li>
  <li><strong>Real-time Updates</strong> - See changes instantly with React's reactive interface</li>
  <li><strong>Clean Interface</strong> - Intuitive, user-friendly design</li>
</ul>
<h2>🛠️ Tech Stack</h2>
<ul>
  <li><strong>React</strong> - Component-based UI library</li>
  <li><strong>CSS3</strong> - Modern styling and responsive design</li>
  <li><strong>React Hooks</strong> - State management (useState, useEffect)</li>
</ul>
<h2>💡 Usage</h2>
<ol>
  <li>Add a new task using the input field</li>
  <li>Mark tasks as complete by checking the box</li>
  <li>Edit tasks by clicking the edit button</li>
  <li>Delete tasks you no longer need</li>
</ol>
